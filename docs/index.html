Website Cost Calculator — free embed demo

This is a live, working copy of the free calculator widget from Project Cost Estimator, embedded on GitHub Pages with the exact two lines a visitor would paste into their own site. No signup, no API key, no tracking added by this demo.

Live widget

Embed it yourself

Paste this where you want the calculator, then load the script once per page:

<div data-pce-widget="general"></div>
<script async src="https://projectcostestimator.com/embed.js"></script>

13 niche presets are available (restaurant, law firm, e-commerce, real estate, SaaS, and more) — see the full embed picker for the complete list and a copy-paste code generator.
